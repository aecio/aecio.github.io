Harmonia & bdi-kit: LLM-Powered Data Harmonization

Developed Harmonia, an agentic system combining Large Language Model (LLM) reasoning, user interaction, and the bdi-kit library to automate data harmonization pipelines[cite: 10, 117, 128]. Also developed bdi-kit, a Python library supporting data harmonization tasks (schema matching, value matching, data standardization) using state-of-the-art methods, including LLMs, with a focus on biomedical data[cite: 9, 118, 119, 126]. This research is part of the ARPA-H BDF Toolbox and DARPA ASKEM programs[cite: 125]. Contributed to a novel schema-matching algorithm leveraging LLMs for training data generation and match selection[cite: 127].

Related Links: Harmonia GitHub bdi-kit GitHub bdi-kit Docs Harmonia Paper [VLDB'25 Submission] Magneto Paper [VLDB'25 Submission]

Auctus: Dataset Search Engine

Designed and developed Auctus, a dataset search engine focused on data discovery and augmentation for analytics and machine learning[cite: 8, 104, 133]. Auctus indexes thousands of public datasets from various sources and supports advanced queries, including finding datasets related to a user's data via joins or unions, and spatio-temporal searches[cite: 121, 133]. Developed novel, efficient sketch-based algorithms and indexes for searching datasets based on attribute correlations and estimating mutual information across tables[cite: 135, 69, 77, 79]. This work was part of the DARPA D3M and NSF programs[cite: 141, 129].

Related Links: Auctus GitLab Auctus Online System Auctus VLDB'21 Demo Paper ICDE'22 Paper (Sketch-based Index) SIGMOD'21 Paper (Correlation Sketches) ICDE'24 Paper (Mutual Information)

Visus: Interactive AutoML System

Developed Visus, an interactive system for Automated Machine Learning (AutoML) model building and curation[cite: 7, 93]. Visus was designed to enable subject-matter experts (SMEs) with limited data science background to create empirical models without coding, thereby automating model discovery and enhancing productivity[cite: 138, 139]. This system was developed under DARPA's Data-Driven Discovery of Models (D3M) program [cite: 122, 138] and was featured in Science Magazine[cite: 140].

Related Links: Visus GitLab Science Magazine Feature [Link from CV] HILDA@SIGMOD'19 Paper

ACHE: Domain-Specific Web Crawler

Led the development of ACHE, an open-source focused web crawler designed for efficient domain-specific content discovery[cite: 11, 123, 150]. Developed as part of DARPA's Memex program, which focused on advancing search capabilities, notably used in efforts to combat human trafficking[cite: 148, 149]. ACHE has achieved significant adoption, evidenced by 430+ GitHub stars and 100K+ Docker Hub downloads, and is used in production by several companies[cite: 153]. Research stemming from this work was published in venues like WSDM and WWW[cite: 152, 81, 83, 98].

Related Links: ACHE GitHub WSDM'18 Paper WWW'19 Paper

Dataset Relationship Discovery & Sketching Algorithms

Developed and analyzed novel randomized algorithms (sketches) for efficiently estimating data correlations and relationships at scale[cite: 135]. This includes methods for join-correlation queries[cite: 79], inner product estimation using weighted minwise hashing[cite: 75, 68], estimating mutual information across tables[cite: 69], and analysis of priority sampling[cite: 71]. These techniques formed the algorithmic backbone for enabling efficient correlated dataset search in systems like Auctus[cite: 77, 135].
